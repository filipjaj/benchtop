Outputs

Eight outputs from one project file

Every output is generated from the same project.json, so the guide, the firmware pins and the case cannot disagree.

01Concept sheet

Closed and inside views, size and cost.

02Checked circuit

24 electrical rules, run on every build.

03Wiring plan

Drawn to scale from the part files.

04Build guide

Flat-pack style, one step per wire. HTML and PDF.

05Parts and shopping

Exact parts with region-aware shop searches.

06Printable case

STL and 3MF, plus a fit-test print.

07Firmware scaffold

Generated pin map and a bring-up test.

08Renders and drawings

Dimensioned drawings and a landing page that links every file.

Install

Install in Claude Code

Then describe what you want to build. The skill asks before each phase.

/plugin marketplace add filipjaj/benchtop
/plugin install benchtop@benchtop

Alpha. Every output is checked by software on each build: closed meshes, electrical rules, drawing checks, firmware compiles. Nothing has yet been printed, soldered or flashed from a Benchtop package, so treat a first build as a prototype and print the fit test first.
