# Luft

Luft sits on your desk and shows temperature, humidity and air pressure on a small OLED. Press the button to cycle through readings and a 24 hour trend. It runs from any USB charger and keeps its data on the device.

Open `index.html` for the overview, or go straight to `guide/index.html` to build it.

| File | What it is |
| --- | --- |
| `guide/index.html` | Assembly guide: 13 illustrated pages, drawn to scale |
| `guide/guide.pdf` | Assembly guide, printable: A4 PDF |
| `files/bom.csv` | Parts list: Every part with a search term and a price |
| `shopping/index.html` | Shopping list: Every part with what to check and shop searches |
| `files/enclosure/luft.3mf` | Enclosure, ready to slice: 3MF with body and lid on one plate |
| `files/enclosure/fit-test.3mf` | Fit test, print this first: Two thin pieces that show in minutes whether your parts fit |
| `files/enclosure/body.stl` | Enclosure body: STL |
| `files/enclosure/lid.stl` | Enclosure lid: STL |
| `files/renders/hero.png` | Renders: Closed, opened up and from above, PNG |
| `files/drawings/index.html` | Drawings: Wiring plan, dimensioned case drawing and pin map |
| `files/firmware/platformio.ini` | Firmware: PlatformIO project with a bring-up test |
| `files/project.json` | The source of truth every other file was generated from |
